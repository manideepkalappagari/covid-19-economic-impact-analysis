
# COVID-19 Economic Impact Analysis

## Project Overview
This project explores the economic and social impact of COVID-19 across Indian states using Python and data visualization techniques. It focuses on changes in GDP, unemployment, sector-wise economic losses, and recovery progress during the COVID-19 period.Analysis of the economic and social impact of COVID-19 across Indian states using Python, Pandas, Matplotlib, and Seaborn. Includes a Jupyter Notebook with bivariate analysis, data visualizations, correlation analysis, and a PowerPoint presentation.

## Objectives
- Analyze GDP before and during COVID-19.
- Compare unemployment rates before and during COVID-19.
- Study the relationship between GDP loss and recovery progress.
- Identify sectors with higher average GDP losses.
- Compare average GDP losses across states.
- Explore correlations between selected economic and social indicators.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

The project includes the following visualizations:

6. Correlation Heatmap of Selected Variables

## How to Run
1. Download or clone this repository.
2. Install the required Python libraries:
   ```bash
   pip install pandas matplotlib seaborn jupyter
   ```
3. Place the dataset in the location expected by the notebook.
4. Open the notebook using Jupyter Notebook or JupyterLab.
5. Run the cells to view the analysis and graphs.

## Dataset
The analysis uses a dataset about India's economic and social conditions during COVID-19, covering state-level and sector-level indicators. The dataset includes GDP, unemployment, migration, vaccination, inflation, health, and recovery-related variables.

## Important Note
The findings depend on the dataset's source, quality, and methodology. Correlation shows an association between variables and does not establish causation. The results should not be treated as official economic statistics without independent verification.
